# Условия использования MysticEgo

Проект редакции для проверки оператором перед включением регистрации с обязательным принятием. Версию утверждённого текста назначает оператор развёртывания.

## Сервис

DarkLie:Zero ведёт проект MysticEgo из России. Контакт по условиям и эксплуатации — [zero.dark.lie@gmail.com](mailto:zero.dark.lie@gmail.com). MysticEgo предоставляет аккаунт Audit и доступ к функциям, назначенным конкретному пользователю. Игровые компоненты и функции бета-версии могут меняться. Обновление программы и правила обработки данных описываются в соответствующих самостоятельных документах.

Проект стремится предоставлять открытый доступ к публичным страницам из разных стран. Доступность и применимые требования зависят от страны, сети, роли оператора и вида услуги. Обязательные права пользователей действуют независимо от этих условий.

## Аккаунт и допустимое использование

Используйте свой аккаунт, защищайте пароль и сообщайте о подозрительной активности. Подключайте только площадки, станции и оборудование, которыми вы уполномочены управлять. Соблюдайте права других пользователей и правила выбранной площадки. Запрещено использовать аккаунт для несанкционированного доступа, вмешательства в чужие устройства или публикации данных других людей без разрешения.

Условия использования сервиса и [лицензия исходного кода](../../LICENSE) действуют в своих областях. Доступ к аккаунту не даёт права на коммерческое использование новой редакции исходного кода. По коммерческим сценариям можно запросить [отдельное письменное разрешение](commercial.md).

## Изменения и обращения

Перед регистрацией показывается версия условий и отдельное уведомление об обработке данных. При изменении существенных условий оператор должен определить способ уведомления, дату вступления в силу и необходимость повторного подтверждения. Вопросы о доступе, ограничениях и спорах можно направить на указанный контакт.

## Мобильный клиент и разрешения

Перед первым использованием мобильный клиент показывает технические сведения о телефоне и объясняет назначение обработки. Завершение инициализации требует ознакомления с уведомлением и явного выбора доступных возможностей. Базовые сетевые функции не требуют предоставления необязательных разрешений. QR-сканирование использует камеру только по действию пользователя; при отказе остаются ручной ввод и обычный вход. Разрешения действуют в пределах возможностей Android, могут быть отозваны; новые функции и расширение доступа требуют отдельного выбора. Пользователь не предоставляет права на управление чужими устройствами, скрытое наблюдение или получение несвязанных с сервисом данных.

При регистрации пользователь подтверждает актуальную редакцию условий, уведомления об обработке данных, лицензии и ознакомление с политикой разрешений. Для существующих аккаунтов изменение версий документов требует повторного рассмотрения в безопасности аккаунта. Лицензия исходного кода PolyForm Noncommercial остаётся без изменения; это условия использования приложения, не изменение текста исходной лицензии.

QR-вход разрешается только для собственного запроса, после сравнения кода на двух устройствах. Не подтверждайте запросы, которые прислали незнакомые лица. QR контакта предназначен для поиска профиля: он не создаёт дружбу, пока пользователь не отправит запрос и получатель его не примет.


Мобильный ассистент может использовать локальный сервер модели, сервер MysticEgo или явно выбранного внешнего поставщика. Доступность и стоимость внешних услуг зависят от конфигурации оператора; пользователь должен получить сведения о получателе до отправки данных. Запросы между собственными активными сессиями подтверждаются на принимающем устройстве. Камера AR и микрофон речи используются только для отдельно выбранных функций, отказ не препятствует обычному входу. Запрещено применять связь устройств для скрытого наблюдения или обхода прав владельца.


Регистрация Mobile Agent является отдельной добровольной функцией. Одноразовый код регистрации предназначен только для собственного устройства. Пользователь может выключить приём, отклонить любой запрос или отозвать ключ через безопасность аккаунта. Регистрация не даёт право на произвольное управление ОС; доступны только явно перечисленные функции.
