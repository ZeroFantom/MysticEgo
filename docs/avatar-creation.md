# Создание аватаров, анимаций и стикеров

## Что доступно в панели

| Результат | Бесплатный вариант | Платный вариант для пилота |
| --- | --- | --- |
| Анимация | **Студия VRM → Приветствие**. Настоящий файл `.vrma` с движением руки. Его можно скачать отдельно или назначить на слот «Приветствие» и сохранить аватар. | [Meshy Animation API](https://docs.meshy.ai/en/api/rigging). Взять один клип через API, проверить суставы и перенести движение в VRMA. |
| Модель | **Студия VRM → Скаут**. Гуманоидный робот, который собирается в браузере из шаблона. Можно сохранить в библиотеке или скачать `.vrm`. | [Meshy](https://docs.meshy.ai/en/api/rigging). Генерация модели по референсу и авториг. Выход Meshy нужно преобразовать и проверить как VRM в [Blender](https://vrm-addon-for-blender.info/). |
| Стикер | **Коллектив → Стикеры → Создать стикер**. Подпись, эмодзи и цвет. Создаёт PNG 384 × 384 и сохраняет его в личной коллекции. | [OpenAI GPT Image](https://developers.openai.com/api/docs/guides/tools-image-generation). Проверить одну иллюстрацию высокого качества с прозрачным фоном, затем нормализовать под лимиты коллекции. |

У каждого бесплатного инструмента один базовый шаблон. Модель и клип создаются локально, а панель передаёт их в библиотеку MysticEgo только при сохранении. Стикер рисуется в браузере и загружается через обычный маршрут добавления в личную коллекцию. Генераторы не отправляют исходные данные внешним сервисам.

Клипы JSON, которые выгружает «Скачать описание движений», содержат настройки процедурных движений. Для импорта в другой совместимый проигрыватель используйте VRMA.

Платные варианты пока не подключены. Их первый пилот должен проверить реальный экспорт, права на использование результата и расходы на один успешный запрос. Секрет провайдера хранится на сервере. Для платного запроса нужен отдельный выбор провайдера и осознанное подтверждение отправки данных.
