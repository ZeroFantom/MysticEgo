# MysticEgo BETA7 R3.2.35

## Публичная страница скачивания приложений (PR #67)
- Полноширинная страница /desktop-downloads с минимальной высотой экрана, полноширинным баннером, навигацией, адаптивным каталогом и нижней частью.
- Все шесть ссылок Windows/Linux сохранены. Внутренняя страница CloudDesk не изменена.
- Проверено на ширинах 390, 768 и 1440 px в четырёх вариантах оформления; 258/258 браузерных проверок.

## Подготовка переноса базы данных (PR #66, первый этап #65)
- Автономный инструмент SQLite → PostgreSQL для сущностей узла и журнала аудита. Проверка целостности, защищённые SQLite-снимки, строгая схема, транзакционный перенос, проверка количества строк и SHA-256 значений, откат при ошибке. Существующая база назначения не перезаписывается.
- Интеграционные проверки успешно прошли на PostgreSQL 16 и 17; сохранены идентификаторы, данные и аудит.
- В полном ZIP и Orchestra Linux включён framework-dependent CLI tools/MysticEgo.DatabaseMigration/out/MysticEgo.DatabaseMigration.dll (.NET 10).
- Инструмент не запускается автоматически, не изменяет подключение работающего сервера, не переносит Auth, не восстанавливает повреждённые данные. Запуск требует остановки всех писателей источника, приватного файла подключения, приватного каталога резервных копий и выделенной пустой базы. Не применять в продуктивной среде до отдельной проверенной процедуры переключения. Задача #65 остаётся открытой.

Предварительный выпуск. Сделайте резервную копию перед обновлением. Изменения R3.2.34 по автоматическому обслуживанию сохранены; установка компонентов на реальном VPS требует проверки.
