# MysticEgo BETA7 R3.2.38

## Восстановление Orchestra и CloudDesk
- CloudDesk: отдельная кнопка восстановления службы обслуживания существующей Orchestra через доверенный SSH. Проверяются VPS, домен, ID узла и SHA-256 сценария; приложение и базы данных не заменяются.
- Orchestra: независимый системный канал восстановления с фиксированным запросом и проверкой прав владельца. Может работать при остановленной обычной службе обновлений, если независимый канал установлен.
- Установщик и обновлённый updater устанавливают независимый канал автоматически. В диагностическом отчёте публикуется состояние восстановления.
- CloudDesk восстанавливает службы действующей R3.2.37 или более новой версии; для независимого восстановления через Orchestra нужна R3.2.38.
- PR #70: серверные и браузерные проверки пройдены; 13 тестов восстановления и обновления, 5 тестов обслуживания, сборка CloudDesk и проверка отчётов.

## Переход с ранее установленной версии
Обновите Orchestra через веб-панель. Если привилегированный канал не появился, используйте актуальный CloudDesk: «Обновление узлов» → выберите VPS → «Определить установленную Orchestra» → «Восстановить службу обслуживания». Повторная установка приложения не требуется. Если оба системных канала отсутствуют, веб-приложение не может самостоятельно получить root. Требуется доверенный SSH через CloudDesk. Реальный VPS в CI не проверен.
