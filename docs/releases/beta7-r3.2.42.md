# MysticEgo BETA7 R3.2.42

## Интерфейс
- Общий переключатель языка пяти веб-панелей: одна форма группы, без вложенной рамки, фиксированная ширина, отдельная стрелка, выравнивание с кнопками темы/стиля. Проверка четырёх языков непосредственно через верхнюю панель. Специализированные переводы продолжаются (#92).
- CloudDesk: реальные этапы SSH «Подлинность → Доступ → Готово», отметки выполненных этапов и видимый итог перед продолжением. При неверном отпечатке требуется независимое подтверждение; автоматического доверия нет.

## Desktop
- AgentDesktop, AuditDesktop, LocalDesktop и CloudDesk: компактная карточка, скачивание проверенного пакета с прогрессом, установка и запуск новой версии из приложения. Отдельное состояние перезапуска, если установка уже завершена, а операция ещё выполняется.
- Сведения о релизе свёрнуты по умолчанию; кнопка обновления доступна также во встроенной веб-панели Agent/Audit.
- Agent/Local сохраняют автоматическую политику; Audit/CloudDesk — подтверждение действия в интерфейсе. Поддерживаются штатно установленные Windows/Linux x64 пакеты, а не произвольная распакованная ZIP-версия.

## MCP
- Временный локальный Desktop MCP: desktop_update_status, desktop_update_check, desktop_update_apply (отдельное нативное подтверждение конкретного проверенного кандидата); clouddesk_ssh_status, локальная загрузка отчётов через отмеченные элементы.
- Веб MCP: доступные вкладки ассистента и вложенные маршруты инфраструктуры; не раскрывает произвольные параметры URL. Только текущий владелец и разрешённое видимое окно.
- Полная переустановка с удалением БД остаётся ручной операцией с подтверждением домена; MCP не вызывает разрушительное действие.

## Проверки и ограничения
- Автотесты Windows/Linux проверяют механизм обновления, контрольную сумму, подтверждение MCP, состояние и повторный перезапуск; Chromium проверяет интерфейс. Реальный запуск новой версии на установленном ПК и реальный SSH требуют приёмки (#104, #106).
- Для появления нового интерфейса требуется переход на R3.2.42 с использованием существующего механизма обновления либо штатного установщика.
- Сохраняются ограничения и открытые задачи R3.2.41: #40, #94 (ИИ и речь), #92 (локализация), #100 (сброс), #102 (Telegram/VK), #93 (приёмка).

Связанные PR: #103, #105.
