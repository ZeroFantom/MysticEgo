# MysticEgo BETA7 R3.2.44 — подтверждение готовности узла

Накопительное исправление R3.2.43, включающее PR #107 после устранения конфликтов с автономным обслуживанием из PR #108.

## Orchestra и хранилище
- Новый SQLite-узел инициализирует реальную схему записей при создании NodeState, до объявления готовности API. Ранее отдельная база аудита могла появляться раньше основного node.db.
- Существующие непустые SQLite-базы и настроенный PostgreSQL не заменяются; проверяется сохранность записей.

## CloudDesk
- При обрыве SSH после начала установки CloudDesk повторно подключается только для проверки результата: доверенный VPS, контрольная сумма ранее переданного скрипта, режим verify без повторного удаления данных.
- Финальная проверка сопоставляет новую локальную, публичную HTTPS и сохранённую идентичность, непустые файлы SQLite, точную утверждённую версию и активные службы Orchestra/Caddy.
- Недоступность таймера обновления, таймера обслуживания или локального сокета отображается отдельным состоянием ремонта; подтверждённая установка не требует нового сброса.
- Сохранены блокировки, автоматическое восстановление LM Studio и зависимостей, выбор опубликованного проверенного релиза и ограничения разрушительных операций из R3.2.43.

## Веб-панели и проверки
- Сохранена анимация входа R3.2.43 и метаданные предпросмотра ссылок; добавлен браузерный тест холодного запуска с задержкой JavaScript.
- Расширены проверки новой SQLite-базы и сохранности данных, несоответствия ID/релиза, отсутствующих файлов, отказа основной службы и отдельного статуса обслуживания.
- Релиз собирается для Windows/Linux и сервера; публикация только после штатных проверок и проверки полного набора файлов и SHA-256. Предыдущий релиз не перезаписывается.

## Ограничения
- Полный сброс по-прежнему требует явного подтверждения владельца, не выполняется автоматически и удаляет локальные данные. Реальный сброс на отдельном VPS и длительная совместная нагрузка остаются задачами приёмки. Не проверялись разрушительные операции на рабочем сервере.
- Для получения этих исправлений достаточно штатного обновления существующих установок; опубликованный пакет не означает, что конкретный VPS уже обновился.
