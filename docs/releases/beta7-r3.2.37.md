# MysticEgo BETA7 R3.2.37

## Служба обслуживания Orchestra
- Обновление Orchestra автоматически устанавливает и восстанавливает локальную службу обслуживания из проверенного пакета. Совместимые старые установочные сценарии обновляют привилегированную службу обновлений до длительных операций.
- Повторные попытки установки с интервалом не менее 120 секунд, в том числе без нового релиза и при недоступности GitHub. Проверяются файлы, сокет, активность и автозапуск таймера; если отчёт отсутствует, инициируется запуск обслуживания.
- Состояние обслуживания и версия отображаются отдельно от обновления приложения. В разделе «Сервисы» владелец может запросить восстановление кнопкой без SSH и CloudDesk.
- В интерфейсе используется название «Служба обслуживания Orchestra». Старые внутренние имена и поля отчёта сохранены для совместимости.
- Экспорт диагностики включает состояние, версию и доступную причину ошибки установки обслуживания. Базы данных и пользовательские настройки не переключаются.
- PR #69: 261 браузерная проверка, 8 тестов автоматического восстановления, 5 тестов обслуживания, проверка форматов отчёта и серверной сборки.

Предварительный выпуск. Проверьте повторный экспорт JSON после обновления Orchestra. Для перехода со старого updater необходим хотя бы один из предусмотренных post-update hooks; updater без обоих hooks не может получить привилегии из веб-панели. Проверка на конкретном VPS ещё не выполнена. Миграция Auth и автоматическое переключение базы остаются отдельными задачами (#65).
