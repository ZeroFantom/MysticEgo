# MysticEgo BETA7 R3.2.43

## Исправления чистой установки
- Fresh SQLite: основной node.db создаётся на этапе запуска узла через существующую схему записей. Ранее основной файл мог отсутствовать до первого обращения, несмотря на успешную проверку live. Существующая непустая SQLite и выбранный PostgreSQL не заменяются.
- CloudDesk: статические systemd-службы останавливаются без ошибочного disable. После установки отдельно проверяются новая локальная и публичная идентичность, сохранённый ID, обе непустые базы, точная версия и активность служб. При ошибке SSH после начала установки возможна только повторная проверка существующего состояния, не повторный сброс.
- Ошибка финальной проверки теперь содержит конкретное невыполненное условие. Полный сброс остаётся необратимым и требует локального подтверждения. Реальный результат на VPS требует отдельной проверки (#100).

## Веб-интерфейс
- При открытии и переключении панелей до загрузки React показывается минимальная анимация, без вспышки заголовка и описания Open Graph. Текст доступен в noscript, метаданные и обложки Telegram/VK сохраняются.
- Поддержано предпочтение reduced motion. Проверяется холодная загрузка всех пяти панелей с недоступным JavaScript-бандлом.

## Проверки
- Регрессия новой базы и сохранения существующих данных, HTTP-метаданные, браузерные проверки и изолированные тесты read-only итоговой проверки.
- Реальная приёмка полной переустановки, внешних карточек и Desktop остаётся в #100, #102, #104, #106; не выполнять повторный разрушительный сброс ради диагностики.
