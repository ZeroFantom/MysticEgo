# MysticEgo BETA7 R3.2.43 — автономное обслуживание VPS

## Orchestra и серверный updater
- Автоматическое восстановление установленной службы обслуживания из доверенного локального релиза, в том числе при недоступном GitHub.
- Проверка существования нужных файлов LM Studio, восстановление домашнего каталога системного пользователя, установка libatomic1/libgomp1, повторная загрузка отсутствующей модели с сохранением профиля. Проверка точного идентификатора загруженной модели.
- Проверка свободной памяти и диска перед развёртыванием, отказ от захвата занятого порта, единые блокировки между updater и локальным установщиком.
- Проверка свежести отчёта, причина сбоя и время следующей попытки; история изменений состояния без постоянных одинаковых записей.

## CloudDesk
- Чистая установка Orchestra выбирает актуальный проверенный архив BETA7, а не исторический архив R3.2.29.
- Проверка одинакового локального и HTTPS ID, готовности SQLite до шести минут и явный маркер успешной установки. Полная переустановка проверяет зависимости и отсутствие параллельной установки до удаления данных, а в конце подтверждает новую идентичность.
- Два ограниченных вызова безопасного восстановления службы обслуживания; отдельные состояния «фоновые проверки» и «нужен ремонт», без повторного разрушительного сброса. Восстановление через доверенный SSH привязано к сессии владельца и ID узла.
- Читаемые этапы установки, отсутствие последовательных дубликатов, причина и время повторной попытки на карточках диагностики.

## Веб-панели
- Вместо краткого показа текста SEO на входе — нейтральная анимация загрузки; сохранены метаданные для ссылок и noscript. Переходы между документами — в поддерживающих браузерах, с учётом reduced motion.

## Проверки и ограничения
- При ручном восстановлении действующего VPS подтверждены установка llmster, загруженная Qwen3 1.7B Q4_K_M, успешная генерация за 2,627 с, шесть активных служб. Это проверка способа восстановления, а не новая сборка на VPS.
- Публикация возможна только после CI и проверки всех упакованных архивов, установщиков и SHA-256. Приёмка чистого развёртывания, сброса на изолированном VPS, длительной одновременной нагрузки и фактического обновления установленного CloudDesk остаётся отдельной.
- Действующие данные не удаляются при обычном обновлении; полная переустановка с удалением данных требует прежнего отдельного подтверждения владельца. Автоматический переход на другой провайдер базы, изменение внешних моделей и создание swap не выполняются.
- Подробнее: [серверное восстановление](../server-maintenance-recovery.md). Связанный PR #108; задачи #40, #65, #94, #100, #102, #104.
