# MysticEgo BETA7 R3.2.36

## Инфраструктура Orchestra
- Диагностика содержит наблюдение за ресурсами, сетевыми связями и экспорт отчёта; развёртывание и настройка распределены по четырём отдельным разделам владельца: Сервисы, AI и речь, Базы данных, Мониторинг.
- Адаптивный интерфейс, карточки состояния и тематическое оформление. Страница моделей направляет к настройке AI.
- Исправлен доступ к отчёту host-worker в Docker через существующий Unix-сокет с проверкой UID, разделены состояния отсутствия, ожидания и ошибки доступа. Права на каталог отчётов исправлены. Bootstrap обновляет установленный updater из доверенного релиза; локальная настройка источника метрик.
- Отчёт JSON, TXT или XLSX: сводка, проверки, телеметрия, сетевые связи с анонимными номерами, статусы разрешённых systemd-служб. Только для владельца Orchestra. Без паролей, токенов, URL, личных сообщений и сырых журналов. История ограничена 120 проверками host-worker на диске, 240 проверками базы, 720 проверками зависимостей, 180 замерами ресурсов; история приложения в памяти сбрасывается при рестарте. Экспорт не запускает нагрузочные тесты.
- PR #68: 261/261 браузерных проверок; тесты экспорта всех трёх форматов, безопасности Excel и ограниченной истории; тесты Unix-сокета и автовосстановления; PostgreSQL 16/17.

Предварительный выпуск. Проверьте диагностику и экспорт после обновления на VPS. Причина отсутствия отчёта на конкретном сервере без его журналов не подтверждена. При отсутствующей локальной службе на Ubuntu 24.04 может потребоваться однократный bootstrap из проверенного релиза. Миграция Auth и автоматическое переключение базы остаются отдельными задачами (#65).
