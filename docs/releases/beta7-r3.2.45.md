# MysticEgo BETA7 R3.2.45 — кандидат

Статус: подготовка и валидация; это не опубликованный релиз. Предыдущий опубликованный prerelease — R3.2.44.

## Изменения
- PR #112: поддержка исторических маршрутов /social и /directory в публичных карточках. Метаданные строятся из доверенной конфигурации, без данных аккаунта и параметров запроса. Плавное последовательное появление действий чата с учетом ограничений анимации.
- PR #114: API черновиков квестов WorldAI по одному факту мира. Авторизация владельца, проверка области мира, идемпотентность, проверка JSON и повтор записи результата при временном сбое. Не изменяет SoulEngine, прогресс или экономику. Нет UI игрока и утверждения квестов.
- Пять веб-панелей получают метаданные версии кандидата.

## Проверки
На исходных ветках #112 (16 успешных проверок) и #114 (8 успешных проверок) подтверждены результаты CI. Для объединённого дерева требуется отдельная проверка. Workflow кандидата использует существующую упаковку R3.2.44 с проверкой SHA-256 предыдущего опубликованного полного архива, платформенные и PostgreSQL тесты, браузерные проверки, CollectiveHttpSmoke, WorldAiQueueSmoke, проверку установщиков и ZIP. Публикуется только контрольный манифест как временный артефакт Actions; GitHub Release не создаётся.
