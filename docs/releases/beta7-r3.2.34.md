# MysticEgo BETA7 R3.2.34

Серверное обслуживание Orchestra (PR #64).

- Встроенный updater устанавливает локальный root-owned worker обслуживания Ubuntu 24.04; повторное развёртывание через CloudDesk не требуется при наличии работающего updater.
- Docker и Compose устанавливаются автоматически даже без активных контейнеров. LM Studio проверяется на наличие загруженной модели; существующая служба восстанавливается при необходимости.
- Локальное распознавание речи: faster-whisper base, CPU, loopback 127.0.0.1:1237, отдельная служба с ограничением ресурсов. Явно заданный внешний endpoint имеет приоритет.
- Диагностика предлагает локальный VPS для мониторинга и отображает состояние компонентов; уведомления о проблемах, восстановлении и доступных релизах.
- Проверка подключения к текущей базе каждые 15 секунд; запуск существующей управляемой PostgreSQL без пересоздания тома. Схема и провайдер сохраняются.
- Серверный цикл обслуживания повторяется через 30 секунд после завершения предыдущего цикла. Неудачные операции повторяются с паузой 15 минут.
- Проверки PR: 255/255 браузерных, 5/5 тестов восстановления, все пять серверных приложений собираются.

Важно: реальная установка модели, распознавания речи и Docker на конкретном VPS требует проверки. Необходима Ubuntu 24.04; для голосового сервиса минимум 3 GiB RAM и 3 GiB свободного места. Если встроенная привилегированная служба обновления отсутствует, потребуется однократный bootstrap. Автоматическая смена провайдера базы, восстановление повреждённых данных и полноценная миграция ещё не реализованы (issue #65). Перед обновлением сделайте резервную копию. 

Предварительный выпуск. В комплекте полный ZIP, Orchestra Linux, Desktop и CloudDesk Windows/Linux, индивидуальные установщики и контрольные суммы.
