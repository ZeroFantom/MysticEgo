# Черновики квестов WorldAI

Владелец Orchestra может запросить сюжетный черновик по одному факту текущего мира. Например, из сообщения о замёрзшей реке модель может предложить задание осмотреть переправу. Черновик хранится в очереди WorldAI. Его создание не меняет мир, записи SoulEngine, опыт или валюту.

## Запрос и получение результата

1. Войти в Orchestra под учётной записью владельца.
2. Взять `id` записи типа `world` или `lore` из `GET /api/v1/world-ai/memory`. Идентификатор факта состоит из 32 шестнадцатеричных символов.
3. Отправить `POST /api/v1/world-ai/quest-proposals` с аутентификацией текущего пользователя. Для одного действия клиента использовать один UUID запроса, в том числе при повторной отправке.
4. После ответа `202 Accepted` читать адрес из заголовка `Location`. Пока состояние равно `pending` или `running`, поле `proposal` содержит `null`. При состоянии `completed` оно содержит проверенный объект. При состоянии `failed` отображать код ошибки.

Пример тела запроса с условными идентификаторами:

```json
{
  "requestId": "53b69a82-507f-4b19-bbc1-a01512099ee2",
  "factId": "b9a34cebcbe040c8992d17c5c69559b3"
}
```

Ответ модели версии 1 содержит `title` (до 100 символов), `description` (до 800), `objective` (до 240), `difficulty` (`easy`, `normal`, `hard`), ссылку `factId` и номер `version`. Строки предназначены для вывода как текст. Сложность описывает сюжет и не задаёт награду.

## Границы и восстановление

- Владельца определяет существующая политика Orchestra, мир — серверный `Node:NodeId`. Во входных данных передаются только `requestId` и `factId`. После смены владельца или идентификатора узла старый черновик через этот API недоступен.
- Ключ повтора действует для пары «учётная запись, мир» в пределах срока хранения записи очереди. Повтор с другим фактом возвращает `409`. При отправке нового запроса неизвестный или неподходящий факт даёт `400`.
- Модель получает снимок выбранного факта без остальной памяти. Дополнительные и повторяющиеся поля, подмена факта или нарушение схемы завершают задание с `invalid_quest_proposal`. Журнал сохраняет код ошибки без исходного ответа модели.
- При недоступности модели действует существующий порядок повторов WorldAI, до пяти попыток. Переполненная очередь отвечает `429`, недоступный журнал при записи запроса — `503`. Обычные квесты доступны независимо от этого процесса.
- Журнал предназначен для одного процесса Orchestra. Завершённые записи участвуют в обычной очистке очереди. Долговременное хранение принятых квестов, подтверждение человеком и обработка их выполнения относятся к следующему этапу.
