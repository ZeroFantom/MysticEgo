# Чаты и профиль

Откройте «Коллектив» и выберите подтверждённый контакт. Микрофон рядом с полем сообщения начинает запись. Остановите запись, прослушайте черновик и нажмите «Отправить голосовое». Поддерживаются записи до 90 секунд и 5 МиБ. Веб-панели нужен HTTPS и разрешение на доступ к микрофону.

Нажмите «Прочитать» под голосовым, чтобы увидеть расшифровку. Первый запрос отправляет аудио в настроенный на Orchestra сервис распознавания. Готовый текст сохраняется в чате и доступен обоим участникам. Без сервиса по-прежнему можно записывать, отправлять и слушать голосовые.

Меню с тремя точками рядом со временем сообщения позволяет ответить, переслать в другой чат с подтверждённым контактом либо удалить своё сообщение у обоих участников. Можно отредактировать свой текст, включая текст ответа. Удалённый оригинал не удаляет уже пересланные копии. Удалённое сообщение отображается в истории без содержимого.

В «Профиле» есть поле «Статус» до 100 символов. Статус виден в шапке переписки и сохраняется между входами. Чтобы убрать его, очистите поле и сохраните профиль.

## Распознавание речи на сервере Orchestra

Orchestra вызывает совместимую с OpenAI точку `/v1/audio/transcriptions` только по запросу «Прочитать». Можно использовать локальный [Speaches](https://speaches.ai/installation/) с faster-whisper. Для установки Orchestra как системной службы на Linux с Docker запустите:

```bash
docker run -d --name mysticego-speech --restart unless-stopped \
  --publish 127.0.0.1:8000:8000 \
  --volume mysticego-speech-models:/home/ubuntu/.cache/huggingface/hub \
  ghcr.io/speaches-ai/speaches:latest-cpu
curl --fail --request POST \
  http://127.0.0.1:8000/v1/models/Systran/faster-whisper-small
```

Укажите переменные окружения службы. Для установки с systemd можно добавить их через `sudo systemctl edit mysticego-orchestra`:

```ini
[Service]
Environment="VoiceTranscription__Endpoint=http://127.0.0.1:8000/v1/audio/transcriptions"
Environment="VoiceTranscription__Model=Systran/faster-whisper-small"
```

Затем перезапустите `mysticego-orchestra`. Для Orchestra в контейнере передайте переменные окружения её контейнеру и укажите адрес, доступный из этого контейнера. Разрешены HTTPS и HTTP на loopback. Для провайдера, которому нужен ключ, передайте `VoiceTranscription__ApiKey` через хранилище секретов или закрытый файл окружения службы.

Файлы голосовых находятся в папке `voice/` рядом с файлом данных Orchestra. Включите её в резервные копии вместе с данными чата. При использовании внешнего сервиса распознавания он получает аудио соответствующего сообщения.
