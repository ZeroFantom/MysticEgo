# Personal assistant workspace direction

Reference: https://knice.tech/ (Astra, KNICE Technologies). Use interaction patterns, not its branding, assets, character, wording or layout verbatim.

MysticEgo keeps its own visual identity and security model. The chat is the main surface, while the side area exposes actual persona, voice settings, existing VRM studio and automation routes. Model information is displayed only from the real API; unavailable features must not have simulated success states.

Future work: multi-conversation history, push-to-talk/STT, approved local commands and graphical workflows, notes/tasks/calendar with explicit account permissions, reminders and opt-in memory, pluggable MCP/skills and desktop continuity. Keep remote access owner-authorized; no silent computer actions, credentials, destructive operations or plugin installation. Avoid displaying fictitious telemetry, music playback, weather or tasks as live data.
