# CloudDesk factory reset

Separate from maintenance, repair and rollback. Use only when the owner explicitly wants a new, empty Orchestra on the same VPS. CloudDesk checks Timeweb IP binding, trusted SSH, exact HTTPS domain and node ID, owner authorization, and a supported native local SQLite profile. Preview is one-use and expires in ten minutes. Type DELETE followed by the exact domain, then confirm the native dialog. The current highest published Beta 7 version and complete archive SHA-256 are checked again. A changed version requires a new preview. Download, transfer, checksum, archive and package checks precede deletion.

Deletes application files, local Auth and node DBs, keys and settings under the application state directory, update history and local model files; does not remove the VPS, DNS, SSH access, OS packages or Caddy certificate store. Other servers keep their own data but must be linked to the new Orchestra identity. External PostgreSQL, prepared database settings, custom/shared Caddy configuration, mounted application storage, additional MysticEgo services and Docker Orchestra are rejected without deleting data. Back up manually before starting if needed. No silent backup is retained by this operation. If installation fails after deletion, use the retained root-only staging directory to diagnose and recover; no automatic second destructive attempt. Test the destructive path on a disposable dedicated VPS before using it with important data.
