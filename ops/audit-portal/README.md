# Веб-панель Audit

В CloudDesk откройте **Обновление узлов → Веб-панель Audit** после входа
в Orchestra под главным разработчиком. Выберите VPS Timeweb или введите
SSH-адрес сервера. Мастер проверит ключ сервера и подключение `root`.

| Размещение | Целевой сервер | URL |
| --- | --- | --- |
| В составе Orchestra | VPS с действующей Orchestra | `https://<домен Orchestra>/audit-portal/` |
| На отдельном домене | Тот же VPS или другой Linux VPS с Caddy | `https://<домен Audit>/audit-portal/` |

Для отдельного домена заранее настройте A-запись на IP выбранного VPS.
Если публикуете IPv6, настройте также AAAA. Caddy должен быть запущен, а
порты TCP 80 и 443 доступны. На Ubuntu зависимости для отдельного сервера
можно установить командой `sudo apt install caddy curl unzip python3`.

В обоих вариантах форма **Регистрация** создаёт аккаунт аудитора в Auth
подключённой Orchestra. Портал на отдельном домене передаёт запросы
регистрации, входа и API в Orchestra по HTTPS. Состояние установки и вывод
установщика видны в журнале CloudDesk.

Исходники панели находятся в `frontend/apps/audit` и общих пакетах
`frontend/packages`. Сборка `cd frontend && npm ci && npm run build`
пишет результат в `apps/audit/dist`. CloudDesk использует Audit из
полного релиза или из этого каталога сборки.
