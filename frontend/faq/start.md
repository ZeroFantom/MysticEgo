# Экосистема MysticEgo

Центральное приложение запускает Auth и Оркестр. Auth создаёт единую учётную запись и игровую идентичность при регистрации в Audit. Веб-панель Оркестра открывается с учётной записью разработчика.

- **Оркестр** одобряет заявки организаций, ведёт каталог Global и Audit, хранит профиль, контакты и сообщения.
- **Global** представляет организацию. Владелец выдаёт доступ сотрудникам и создаёт Local для конкретных площадок.
- **Local** представляет одну площадку и выпускает профили её Agent.
- **Agent** работает на клубном ПК. Команды доступны через Local, резервный Global и панель управления Оркестра.
- **Audit** работает на личном ПК и подключается напрямую к Оркестру. Подать заявку на Global можно и из веб-портала Audit с главного сервера.

В AuditDesktop войдите и выберите личный Audit или доступный Global. При запуске Local загрузите конфигурацию площадки из Global. Комплект Agent подключается к своему клубу автоматически и открывает гостевой сеанс.
