# Ассистент, команды и диагностика

Быстрые команды строят параметры по каталогу ядра. Результат отображается карточкой и в исходном JSON. Журнал содержит оператора, время, адресата, итог и подробности. В диагностике доступны история CPU, памяти и трафика, скорость связи с родителем и число Audit на связи.

## Локальная модель

Запустите `MysticEgo.exe` на Windows или `./mysticego` на Linux. MysticEgo проверяет LM Studio, при необходимости устанавливает фоновую службу llmster, запускает локальный сервер, скачивает модель и загружает её в память. Ход подготовки и результат контрольного запроса видны в журнале. Для скачанной Qwen3.5 9B MysticEgo запрашивает итоговый текст с выключенным режимом рассуждения. Если модель недоступна, лаунчер проверяет более лёгкие установленные варианты.

| Узел | Модель по умолчанию | Контекст |
|---|---|---:|
| Agent и Audit | Qwen3 1.7B Q4_K_M | 4096 |
| Local | Qwen3 4B Q4_K_M | 6144 |
| Global и Оркестр | Qwen3 8B Q4_K_M | 8192 |

`--no-lm` отключает подготовку для технического запуска. Локальный API модели слушает `127.0.0.1:1234`. Статус и рекомендуемая модель доступны в панели «Ассистент». На сервере с контейнером модель может подготавливаться внутри окружения роли.

## Действия и MCP

В Audit откройте «Ассистент» или кнопку чата рядом с уведомлениями. В истории сохраняются последние 40 сообщений этого аккаунта на текущем узле. Чтобы настроить облик и движения, откройте «Студию VRM». AuditDesktop использует аватар аккаунта. Прежнюю локальную настройку можно скопировать в аккаунт из студии на своём ПК.

Вкладка «Ассистент» показывает предложения запуска заранее выбранных приложений, поиска, YouTube и диагностики. Запуск приложения подтвердите в панели. Псевдонимы назначаются в AuditDesktop после входа. Установленные WARP и zapret можно привязать к псевдониму. Ссылки на источники доступны в панели.

`POST /mcp` принимает JSON-RPC 2.0 с пользовательским bearer-токеном. Используйте `initialize`, `tools/list` и `tools/call`. `node.status` возвращает состояние текущего узла, `club.info` — адрес и справку клуба. На Agent/Audit в локальном сеансе у владельца доступны `desktop.windows` и `desktop.launch.propose`. Последний возвращает предложение, которое нужно отдельно подтвердить в API. Global/Local/Оркестр показывают доступную диагностику агентов с параметром `targetId`.

Правка в чате получает только выбранный черновик, показывает вариант до отправки и оставляет окончательный текст за пользователем. Помощник гостя отвечает с учётом адреса и описания клуба, заданных в Global.

## Автоматизация и мониторинг

На Windows войдите в AuditDesktop, запишите клики и сохраните JSON. Для воспроизведения по умолчанию разрешены `notepad`, `mspaint` и `calc`. Список настраивается перед запуском Agent или Audit. Загруженный сценарий воспроизводится в активном окне выбранного процесса после входа оператора и подтверждения команды. Остановка на целевом ПК — Esc.

На Linux-сервере с Docker Compose Оркестр может запустить Prometheus и Grafana на локальных портах 9090 и 3000.
