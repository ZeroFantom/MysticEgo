# Оркестр, Global, Local, Agent и личный Audit

**Оркестр → Global → Local → Agent**. Ветвь домашних устройств подключается отдельно: **Audit → Оркестр**.

1. В Audit зарегистрируйтесь и подайте заявку с названием организации, адресом, контактом и описанием.
2. Разработчик открывает заявку в Оркестре, одобряет её, проверяет карточку и задаёт адрес сервера Global. Для запуска доступны SSH и конфигурация. После подключения создатель получает свою панель Global внутри AuditDesktop.
3. В Global заполните данные филиала и скачайте его конфигурацию Local. На сервере клуба или администраторском ПК откройте конфигурацию в AuditDesktop и войдите с полномочиями владельца. Local сам соединится с Global.
4. В Local откройте **Комплект Agent** и скачайте Windows- или Linux-архив. Распакуйте его на гостевых ПК и запустите AuditDesktop. Конфигурация комплекта уже содержит связь с этим Local и его Global. Для готовых копий положите скачанный `club-assignment.json` рядом с приложением.
5. На личном ПК достаточно войти в AuditDesktop и нажать **Открыть личный Audit**. Оркестр показывает подключение Audit в сети. Установка и доступ к домашнему устройству остаются у владельца.

Для теста используйте отдельные компьютеры: Auth и Оркестр, Global, Local, два Agent и два Audit. При первом подключении сервер закрепляет роль за компьютером. Клубные роли размещаются на отдельных машинах.

## Гостевые сеансы и обновления

Кнопка временной сессии доступна, пока Agent связан со своим Local или Global. Гость получает справку клуба и локальный диалог. Запись и воспроизведение сценариев требуют входа с правами на целевой ПК.

Опубликуйте полный publish Agent как ZIP из Local или Global. Системные файлы службы `Api.Agent.dll`, `Api.Agent.deps.json` и `Api.Agent.runtimeconfig.json` лежат в корне ZIP. Agent выбирает наиболее новую версию с верной подписью из двух источников, ждёт окончания гостевого сеанса и снижения нагрузки. При сбое старта возвращается предыдущая версия.

## Адреса

Auth 5400, Оркестр 5500, Global 5100, Local 5200, Agent 5300, Audit 5350. Для публичных адресов используйте HTTPS. Local может работать по HTTP на частном адресе клуба. Сервер Global можно установить через SSH с проверенным ключом хоста. Docker-вариант использует Linux x64.
